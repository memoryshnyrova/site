# Сайт памяти Ольги Вадимовны Шныровой

Сайт памяти историка Ольги Вадимовны Шныровой (28.10.1957 – 06.11.2025): вехи жизни, биография, карта летних школ и встреч, воспоминания коллег, библиография, интервью и лекции. Русская и английская версии.

## Что в архиве

```
index.html        весь сайт: разметка, стили, скрипты и тексты
europe.json       контуры стран для карты (Natural Earth через world-atlas, 1:50m)
img/              фотографии и обложки книг
src/              исходники для пересборки index.html
  template.html   шаблон страницы
  data.json       тексты: биография, воспоминания (RU/EN), библиография, интервью
  build.py        собирает index.html из шаблона и данных
```

## Как опубликовать на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое архива (файлы `index.html`, `europe.json`, папки `img` и `src` должны лежать в корне).
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу вида `https://<имя-аккаунта>.github.io/<имя-репозитория>/`.

Свой домен подключается там же, в **Settings → Pages → Custom domain**.

### Большой файл: книга «Иваново. Город (не)невест»

Файл `files/ivanovo-gorod-ne-nevest.pdf` весит 56 МБ. Через браузер (кнопка **Add file → Upload files** на сайте GitHub) можно загрузить только файлы до 25 МБ, поэтому этот файл так не пройдёт. Есть два простых способа:

1. **GitHub Desktop** (бесплатное приложение GitHub для Windows и Mac). Откройте в нём репозиторий, скопируйте файл в папку `files`, нажмите **Commit**, затем **Push origin**. Ограничение там 100 МБ на файл, книга проходит.
2. **Командная строка**, если привычнее: `git add files/ivanovo-gorod-ne-nevest.pdf && git commit -m "Книга про Иваново" && git push`.

Всё остальное (включая Книгу памяти, 1,2 МБ) можно загружать через браузер.

## После публикации: превью в соцсетях

Чтобы при пересылке ссылки в Telegram, Facebook, VK и других сетях подтягивалась карточка с портретом (`og-image.jpg`), соцсетям нужен полный адрес картинки. Поэтому после того как сайт заработал:

1. Откройте `src/build.py` и впишите адрес сайта в строку `SITE_URL = ""`, например `SITE_URL = "https://memory-shnyrova.github.io/site/"` (со слешем на конце).
2. Запустите `python3 build.py` из папки `src`. Скрипт пересоберёт `index.html`, добавит в него canonical и полные адреса для превью, обновит `robots.txt` и создаст `sitemap.xml`.
3. Загрузите обновлённые файлы в репозиторий.

Проверить карточку можно в [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) или отправив ссылку себе в Telegram.

Что уже прописано в `index.html`: заголовок и описание страницы для поисковиков, Open Graph и Twitter-карточка (отдельный заголовок и описание, чтобы не повторять друг друга), разметка schema.org о персоне (даты, место рождения, профили на Academia.edu, Google Scholar, Arzamas и сайте издательства), иконка сайта `favicon.svg`.

## Как устроены разделы

Сайт — одна страница с разделами-«страницами», переключение идёт через адрес после `#`:

| Адрес | Что открывается |
|---|---|
| `/` или `#life`, `#map` | Главная: первый экран, вехи, превью биографии, фото, карта, превью воспоминаний и трудов |
| `#bio` | Биография полностью |
| `#memories` | Все воспоминания |
| `#works` | Библиография с поиском и фильтрами |
| `#voice` | Интервью и лекции (на странице трудов) |
| `#share` | Блок «Поделитесь воспоминанием» |

На эти адреса можно давать прямые ссылки, например `…/#works` для учёных.

## Как править тексты

Проще всего править `src/data.json`, затем пересобрать сайт:

```
cd src
python3 build.py
```

Нужен Python 3 и библиотека Pillow (`pip install pillow`) — она нужна, чтобы прочитать размеры фотографий. Скрипт перезапишет `index.html` в корне.

- **Новое воспоминание** — добавьте объект в массив `memoirs`: имя, место и год знакомства, подпись, цитата для карточки и полный текст, всё в двух языках (`ru`, `en`).
- **Новая работа** — добавьте объект в массив `pubs`: авторы, название, выходные данные (`src`), год, язык, тип (`book`, `article`, `chapter`, `essay`, `edit`), ссылка (`url`, или `null`, если ссылки на саму работу нет), `full: true`, если по ссылке полный текст, и `title_en` — перевод названия для английской версии.
- **Вехи, места на карте и подписи к фото** — в `src/template.html`, в массивах `TL`, `PTS` и `PHOTOS`.
- **Новая фотография** — положите файл в `img/` (jpg, по длинной стороне до 1400 px) и добавьте его имя в `PHOTOS`.
